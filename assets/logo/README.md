# Logo assets

The README uses the colored horizontal logo on light backgrounds and the white
monochrome logo on dark backgrounds. Icons and favicons are included for other
uses.

Wordmarks are SVG paths, not text, so no font installation or network request is
needed to render them. The PNG export uses the same outlined artwork.

The wordmark outlines were generated from DejaVu Sans Mono Bold. Its upstream
[font license](FONT_LICENSE.txt) is included for attribution. No font files are
bundled in this repository.
